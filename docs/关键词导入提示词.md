# 向已有业务库导入五字段关键词

先用已验收的扩充脚本，从 Excel 和原关键词库生成 `keyword-expanded.db`：

```powershell
.venv\Scripts\python -X utf8 scripts/expand_keyword_db.py --source "D:\你的目录\keyword.db" --excel "D:\你的目录\example.xlsx" --output "D:\你的目录\keyword-expanded.db"
```

如果旧库的 C 是用例编号、B 是用例名称，再加 `--excel-key-order ACBD`。脚本只扩充在 Excel 和旧库中都存在的四字段键。每个不同的指标名称生成一条记录，并沿用原关键词。

确认 `--target` 指向当前业务 SQLite 库。先预览，核对新增和已有相同记录的条数：

```powershell
.venv\Scripts\python -X utf8 scripts/setup.py --import-keywords --source "D:\你的目录\keyword-expanded.db" --target ".\data\review.db"
```

停止 API 和 Worker，备份业务库，再执行导入。管理员用户名必须对应库中已启用的管理员：

```powershell
.venv\Scripts\python -X utf8 scripts/setup.py --import-keywords --source "D:\你的目录\keyword-expanded.db" --target ".\data\review.db" --admin-user "你的管理员用户名" --apply
```

导入保留用户、报告和批次数据。新增词条写入审计，并将五字段精确命中的项置为待审查。相同词条可重复导入，遇到不同关键词、已软删除词条或待审批申请时整批停止。旧批次继续执行、补审以及新批次均读取最新生效的五字段词条。旧四字段词条和快照保留供追溯。

如果是首次创建业务库，使用[正式环境初始化](正式环境初始化.md)。
